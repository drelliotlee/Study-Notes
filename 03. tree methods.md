# Decision trees
- How to split
	- on numerical features
		- sort all values, bin into historgrams. consider split at the midpoint of every bin
	- on categorical features + numerical target
		- sort labels by target mean. consider split at every midpoint
	- on categorical features + binary target
		- at the end of every serial tree, calculate gradient/hessian ratio per label
		- roughly says "did we overpredict/underpredict, weighted by how confident we were"
		- sort and split along this metric
	- on categorical features + multiclass target
		- do K problems in parallel, each tree is trying to solve one-vs-all binary problem
- How to determine best split from candidate splits
	- regression
		- for each candidate, compute variance reduction: var(parent) - var(child1) - var(child2), choose the greediest one
		- ![300](03.%20tree%20methods-1774879906057.webp)
		- ![201](03.%20tree%20methods-1774879938003.webp)
	- classification
		- for each candidate split, calculate entropy loss / gini impurity of parent - child1 - child2
		- ![214](03.%20tree%20methods-1774880043911.webp)
		- ![300](03.%20tree%20methods-1774880062151.webp)
		- entropy will be max when node is 50-50 btw labels
		- entropy will be 0 when a node is pure/all 1 label
- When to stop splitting?
	- pure leaf node (classif)
	- max tree depth reached
	- not enough variance reduciton / entropy reduction
- New unlabeled point + trained tree. How to infer/predict label?
	- regression → average of all training pts in final node
	- ![300](03.%20tree%20methods-1774880275803.webp)
	- classification → whatever label is majoriy in final node

# Boosting vs Bagging
- boosting = serial trees, each predicts residuals of previous. final prediction is sum of predictions of all trees
- bagging = parallel trees, each trained on 
	- subset of rows (same N, but with replacement ~63%)
	- subset of features (sqrt(F), reshuffled at every split level)
- boosting reduces bias / sequence of experts correcting each other
- bagging reduces variance / wisdom of crowds

# History of Models
- Decision trees → Random forests
	- deterministic → bagging
	- less variance, higher prediction accuracy
- Random forests → Gradient boosting
	- bagging → boosting
	- more accuracy than just averaging trees
- Gradient boosting → xgboost
	- overfitting and oversplitting penalties
	- less overfit
- xgboost → lightgbm
	- faster training due to
		- consider every possible split → histogram based splits
		- all nodes on same level evaluated → always split node with highest loss reduc, regardless of level
- lightgbm → catboost
	- mostly improvements in ease of use
		- native categorical encoding
		- less hyperparameter training required
	- inference much faster
		- symmetric trees AKA every node on same level uses same split
		- inference is essentially not a tree anymore, just a lookup table with 1 threshold per dimension
