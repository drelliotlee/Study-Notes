# Information Theory
- entropy/information of a 90-10 coin > 50-50 coin (maximized when all outcomes equally likely)
- intuitive definition of entropy of r.v. Y:
	- how many yes/no questions does it take to know this rv's outcome?
		- but not for single outcome, but for (# of q's to know sequence of outcomes n)/n
		- but that value changes depending on n, so value it converges to as n→∞
		- H(Y) = lim_{n→∞} (𝔼[Lₙ]/n) 
			-  L_n is the # of yes/no questions (bits) required to identify the outcome sequence (Y₁,…,Yₙ)
- easy to calculate definiton:
	- H(Y) = -∑ P(y) × log₂(P(y))
		- Surprise of seeing an outcome y = -log₂(P(y))
		- entropy is surprise of all outcomes, weighted by the probability of those outcomes
- shannon's source coding theorem showed that **Matches Intuition Version** = **Easy to calculate version**

NAPKIN PROOF FOR 90-10 COIN
Easy to calculate version: 
H(Y) = -[0.9 × log₂(0.9) + 0.1 × log₂(0.1)]
H(Y) = 0.469

Intuitive version:
for n=1, the optimal line of questioning is "is it H?"
fully identifies the sequence in 1 question, so E[L₁] / 1 = 1

for n=2, the optimal line of questioning is "Is it HH? If not, is it TH?, if not, is it TT?"
This will identify the outcomes in 1 question 81% of the time, 2 questions 9% of the time, and 3 questions remainder of time.
(Expected number of questions)/2 = E[L₂] / 2 = 0.645

for n=3, optimal line of q's: is it HHH? if no HTH or THH? if yes HTH, if no, HHT? if no, TTT or HTT? if yes TTT? ... etc 
it will turn out that E[L₃] / 3 ≈ 0.533

lim_{n→∞} (𝔼[Lₙ]/n)  =  lim_{n→∞} {1, 0.645, 0.533, ...} = (trust me bro) = 0.469 

# 2nd law of thermodynamics
-  an isolated system is overwhelmingly likely to move
	- FROM states of low entropy (states which require more precise/narrow conditions to define)
	- TO states of high entropy (states which can be described with broader conditions)

# Frequentist vs Bayes
- Bayes: P(new distrib parameter | data obseved, prior distrib parameter)
- Freq: P(seeing this data | assumed fixed parameter)

- Bayes makes assumptions about prior distribution
- Freq makes subjective assumptions about how and how much constitutes statistical significance

- Bayes produces (distribution around parameter) → 95% confid interval around location of p
- Freq produces p-value (prob this outcome was produced by our assumption), say our assumption was wrong if less than 5% chance

# Bias vs Variance
- high bias ≈ simpler models ≈ underfits data
	- fitted lines can never fit curves well, no matter what
	- this model type is "inherently biased"
- high variance ≈ complex models ≈ overfits data
	- fitted curves will change a drastically with every possible observed sample
	- this model type has "high variance over possible observed sample"
