# Big Data & Computer Science
- 1970: Codd lays theoretical foundations for relational databases
- 1976: ANSI SQL turns the math into a standardized programming language
- 1979: Selinger publishes methods for major query optimizations
- 2003: Google publishes GFS and MapReduce, theoretical foundations for HDFS
- 2006: HDFS invented. Distributed data can now be processed
- 2007: NVIDIA releases CUDA. GPUs are now super efficient at linear algebra
- 2009: pandas released for python. Start of python challenging R as the language of ML
- 2010: scikit-learn released. Python gaining further ground
- 2010: ImageNet released. First time people have a massive labeled dataset of images. The gold standard for computer vision benchmarking for a decade.
- 2010: kaggle launched. ML becoming more popular in public mindset.
- 2012: Spark released. Key idea: process data in RAM instead of slow read/writes to hard drives. Hadoop + MapReduce are now largely obsolete. 
- 2015: Tensorflow released. Dominant deep learning framework for next several years. 
- 2015: Keras released. User-friendly front-end for Tensorflow and Theano. Deep learning accessible to programmers and data analysts without PhDs or deep math backgrounds. 
- 2017: Pytorch released. Although Torch was released in 2016, pytorch was when really gained adoption. Main advantages were easier to use and more pythonic than tensorflow. 

# Classical ML/Tabular Data
- 1957: K-means clustering invented
- 1984: CART decision trees invented. 
	- Key idea (Binary classification version): keep finding the next most greedy split which maximizes gini impurity on the labeled training data. 
	- Key idea (Regression version): keep finding the next most greedy split which maximizes the mean-squared error on the labeled training data.
	- Until this point, decision tree methods are still determinstic.
- 1992: SVMs published
	- Key idea: First version is hard-margin (major weakness is cannot deal with a single misclassfied point violating the boundary)
- 1992: SVM major development #1
	- Key idea: Kernel trick to handle non-linearly separable data by implicitly mapping points into a higher-dimensional space where a flat separating hyperplane becomes possible. 
- 1995: SVM major development #2. 
	- Key idea: Soft margin allows some misclassification via a "slack variable" to tolerate points on the wrong side.
- 2001: Random forests published
	- Key idea: Decision trees overfit, so use a random subset of training data and random subset of features to find greedy split to create many trees, then let the final trees vote. 
	- "Wisdom of many imperfect learners" becomes a dominant concept
- 2001: Gradient boosting published
	- Key idea: Instead of building many parallel trees (random forests, build them sequentially where next tree aims to predict the residual errors of the previous tree. Final prediction is sum of predictions of all trees.
- 2014: XGboost published. Dominates kaggle.
- Key idea: add regularization penalties for (1) adding another layer to a tree and (2) splits with very few samples on one side (outlier-driven splits)

# AI/Neural Networks
- 1957: Perceptron published
	- Key idea: First neural network with a single layer, binary classification, binary activation, but still first fundamental idea of updating weights over time epochs
- 1969: Paper proves perceptrons cannot solve non-linearly separable problems requiring XOR-like logic.
	- First "AI winter" starts.
- 1973: Lighthill report in UK & DARPA funding cuts in US → Deeper AI winter
- 1986: Backpropogation invented for multilater perceptrons MLPs. 
	- Key idea: After network makes a labeling prediction, use the error in prediction to slightly update the weights & biases, make a new prediction, repeat.
	- This briefly re-ignites AI interest, but ultimately under-delivers again (why? compute power still too expensive to be practical?) and most of the ML world favors SVMs and tree methods over neural nets in this AI winter until 1993.
- 1990: RNNs published.
	- Key idea: Weakness of MLPs is inputs in sequential data (i.e. text) are completely independent. RNNs predict next word based on a hidden state which holds past information. 
- 1997: LSTMs published.
	- Key idea: Weakness of RNNs was vanishing gradient problem. Hidden states were fed forward through both forget & input gates to control which allows information to be forgotten or added. Instead of tanh function which vanishes over time, we use a sum so derivatives dont vanish. 
- 1998: CNNs published
	- Key idea: Weakness of MLPs is inputs have zero concept of spatial awareness, just all independent information. Also explosion of weights & biases as input dimensions increase. CNNs shared weights between nearby pixels.
	- Although the core math behind CNNs exist here, still not practical in the real world yet because (1) not enough compute power for anything more than MNIST 28x28greyscale images. This would be solved by CUDA. and (2) not enough large labeled datasets of images for training. This would be solved by ImageNet.
- 2006: Pretraining published
	- Key idea: Initialize weights in a better starting position by train each layer greedily and in isolation once at the start. 
	- This largely turned out to be a band-aid fix for the time being, and was superceded by superior methods in the future
- 2010: ReLUs first applied to neural nets (although first proposed in 2000)
	- Key idea: Instead of Sigmoid, use a function that only has slope 0 or 1 so that multiplying slopes over layers doesnt make the gradient vanish. 
- 2012: AlexNet published. ReLUs superiority established in practice. 
- 2012: Dropout published
	- Key idea: on each training pass, remove certain neurons for the feedforward and backprop. Train an imperfect network to avoid overfitting. 
- 2013: Google releases Word2Vec famously known for `king - man + woman = queen`. massive pretrained set of embeddings mapping 3 million english words to a 300 dimensional vector. It also came with many new NLP algorithms to deploy on your own new training data, but that was less important.
- 2014: Seq2Seq published. 
	- Key idea: Use encoder-decoders for sequence-to-sequence tasks
- 2014: GANs published
	- Key idea: a generator creating fake data vs a judge who decides if real or fake
- 2015: Batch Normalization published
	- Problem: During feed-forward, the distribution of activations in each subsequent layer changes. So for each input, the layers weights & biases are chasing moving targets. Many trainings failed to ever converge.  
	- Key idea:  By normalizing the activations after each feed-forward, the layer is learning about a standardized target. 
- 2015: ResNet published
	- Problem: ReLUs solved the derivative of activation function vanishing, but the derivative of the weight matrix is also part of the gradient from the chain rule, so gradient still vanishes after many layers. ResNet allowed information to skip over non-informative layers entirely.
	- Key idea: instead of feeding forward `y = ReLU(W·x + b)`, use `y = x + ReLU(W·x + b)`so even if the second parts derivative has vanished, we still backpropogate the gradient through a slope of 1.  Furthermore, for noninformative layers, the W will be zero, meaning we just feedforward through a transparent layer.
	- Neural nets of 100+ layers now practical.
- 2015: Attention mechanism published
	- Key idea: Basic ideas of the transformer mechanism (elaborate this point better for me)
- 2017: Attention is All You Need
	- Key idea: Instead of each next word transforming the memory sequentially 1 by 1, every word attends to every other word in parallel. NLP possible for the first time on significantly longer texts. 
- 2018: BERT
	- Key idea: Bidirectional encoder representations from transformers. Pre-train a transformer on massive unlabeled text using masked language modeling (predict randomly masked words) and next sentence prediction. 
- 2018: GPT released by OpenAI

# Cultural Notes
- 1997: IBMs DeepBlue defeats Garry Kasparov in chess, popularized as a victory for AI
	- in reality it was not RL in any sense, just a mixture of slightly-smarter brute force search of all possible outcomes, combined with human-coded heuristics for smart strategies.
- 2006: Netflix offers 1 million dollars competition
- 2011: The split between academia and industry is wide. 
	- AI in production for busineses is tabular data, SVMs, and mostly logistic regression. Academia cares about deep learning.
- 2012: Harvard Business Review publishes "Data Scientist: Sexiest Job of the 21st Century" mass, often haphazard hiring of data scientists. Often cited as the start of the DS goldrush and DS bootcamps
- 2013: DeepMind demonstrats AI playing Atari with RL only, no hardcoded rules
- 2015: Around this time, Python has solified its lead over R as the primary ML language, solidified by the introduction of the @ operator for matrix multiplication, as well as Tensorflow and Keras being in python. 
- 2016: AlphaGo defeats Lee Sedol using neural networks (given a current board state, predict next move played, trained on millions of pro game examples of what the next move was) then reinforcement learning (using that intial mapping to play against itself millions of times, and adjusting the weights based on whether it eventually won or lost)
- 2022: The end of the DS goldrush. DS job openings dropped 38%, market was flooded with bootcamp graduates.
